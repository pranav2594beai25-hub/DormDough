# 💰 DormDough - Student Expense Tracker

DormDough is a modern and user-friendly **Student Expense Tracker** designed to help students manage their daily expenses, monitor their spending habits, and stay within their monthly budget.

The application features a clean dark-themed interface with dedicated pages for tracking transactions, setting budgets, and viewing spending reports.

---

## 🚀 Features

- 🏠 Dashboard to view overall expenses
- 📋 Transaction History
- ➕ Add New Expense
- 🎯 Monthly Budget Management
- 📊 Expense Report with Category Breakdown
- 📱 Responsive and Modern UI
- 🌙 Dark Theme Design
- 🧭 Easy Navigation Between Pages

---
